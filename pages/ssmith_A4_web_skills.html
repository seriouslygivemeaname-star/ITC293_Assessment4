Introduction to Web Skills

This page explains the web development skills used to create the Assessment 4 AerisAg portfolio website. The site demonstrates HTML5 structure, external CSS styling, JavaScript form validation, consistent navigation, image use, validation testing and reusable page design.

The website has been developed as an electronic work portfolio for AerisAg, a company focused on drone mapping, GIS analysis and land management. The web design supports this theme by presenting skills and examples in a consistent, professional and easy-to-navigate format.

Web Development Capability

HTML5 Structure

The website uses HTML5 document structure, semantic sections, headings, paragraphs, lists, links, images, tables, forms, metadata and footer content.

External CSS

Styling is controlled through an external CSS file. This supports consistency, reusability and easier maintenance across all website pages.

JavaScript Form Validation

JavaScript is used on the newsletter form to display a welcome message, check required fields and provide feedback after the form is completed.

Validation and Testing

HTML and CSS validation tools were used to check code quality. Navigation, layout, images, form behaviour and screen-size usability were also tested.

JavaScript Newsletter Form

As part of Assessment 4, I added an HTML5 newsletter signup form for AerisAg. The form opens in a new browser tab from this Web Skills page and demonstrates the use of HTML5 form controls, CSS form styling and JavaScript validation.

The JavaScript displays a welcome alert when the newsletter page loads. When the user submits the form, JavaScript checks that the required First Name, Last Name and Email Address fields have been completed. If required information is missing, an alert is displayed and the form does not submit.

When the form is completed correctly, a thank-you message is displayed and the user is returned to the Web Skills page. This avoids the missing server-side processing file problem while still demonstrating form validation and user feedback.
